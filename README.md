## 1. The Problem & Solution
* **The Problem:** Urban and suburban neighborhood ("Mtaa") residents often struggle to find trustworthy local artisans (plumbers, electricians, cleaners, tutors, repair technicians) because word-of-mouth referrals and estate WhatsApp messages get buried quickly[cite: 2, 3].
* **Our Solution:** MtaaConnect provides a dedicated neighborhood feed where residents request services or vouch for reliable workers, and local service providers showcase their skills and community reputation[cite: 2, 3].

---

## 2. Core MVP Features
* **Accounts (Registration & Login):** Email/password authentication with JWT-protected sessions[cite: 3].
* **Profiles:** Displays user name, neighborhood/estate location, role (`Resident` or `Service Provider`), services offered, contact info, and post history[cite: 3].
* **Posts:** Main neighborhood feed for service requests, worker recommendations, community alerts, and provider availability[cite: 3].
* **Comments:** Threaded replies for referrals, follow-up questions, and peer vouching[cite: 3].
* **Responsive Design:** Mobile-first interface built for smartphones and desktop screens[cite: 3].
